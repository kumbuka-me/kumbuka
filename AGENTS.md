## ProjectAtlas

Use ProjectAtlas for repository navigation and code discovery.

- Read the installed ProjectAtlas skill at startup and after context compaction.
- Use `atlas next <task>` before broad repository searches or reading files.
- Follow ProjectAtlas recommendations to narrow to the relevant files.
- Prefer `atlas summary`, `atlas search`, `atlas outline`, and exact `atlas slice`
  calls over reading entire files unnecessarily.
- Run `atlas watch --once` after changing source files when further Atlas queries
  depend on the changes.
- Use broad filesystem searches only when ProjectAtlas cannot answer the query.
